# SCH_gitHub_Homework
자기주도학습 githib과제

아직 진로가 정해지지 않았습니다.
그래서 억지로 쓰기보다 2학년 1학기 방학 계획을 쓰고자 합니다. 

git/gitHub랑 Linux 공부할 생각입니다. 
둘다 공통적으로 코딩을 하는 사람으로서 알아야한다는 이야기를 들었습니다.
실제로 협업을 위해서 git/gitHub를 많이 사용하는데, 어떤 일로 인해 깃허브를 하게 되었는데 쉽지 않더라고요.
아무래도 지금은 다른사람과 협업하는 일이 없다보니 당장은 문제가 없겠지만, 추후 힘들어질 수 있으니 공부할 생각입니다.

Linux도 알면 좋다고 들어서 일단 교재를 살 예정입니다. 

하지만 이론만 배우면 금방 잊기도 하고 직접 경험하는 게 좋다고 생각되어 작은 규모의 프로젝트로 실습도 병행해볼까 합니다.
영단어 책 사놓은게 있어서 그걸 이용하여 영단어장을 만들 예정입니다. 
비록 아직 미숙한 실력이기에 AI를 이용하되 왜 이런 코드인가, 이 방법 말고도 이런 방법이 있지 않은가의 방식으로 결과보다 '만드는 과정'에 중점을 둘 것입니다.

그래도 과제가 '진로계획 작성'이니까 간략하게 써보겠습니다.
1. 일단 2학년은 자격증과 분야 탐색 예정입니다.
   특정 분야를 정해야하는데 아직 관심있는 분야가 없어 이것저것 하면서 흥미있는 분야를 탐색하는 것입니다.
   사실 2학년때 미리 공부를 해야 3학년때 대회 같은 것도 나간다는 이야기를 들었는데... 계획을 이렇게 짜도 괜찮은 건가 막막합니다.
2. 3학년이 되면 정보처리산업기사를 딸 예정입니다.
   사실 정보처리기사를 따면 정보처리산업기사는 없어도 된다, 라는 이야기를 들은적이 있는 거 같지만 일단 시도해보겠습니다.
   자격증 하나에만 시간을 보낼 수는 없죠. 대회나 프로젝트를 통해 경험을 쌓고 포트폴리오를 채우고 싶습니다.
   그리고 틈틈히 입사공고 같은 것을 찾아보며 '현재 기업들이 요구하는 능력'을 알아보고 싶습니다.
   사실 제 목적은 더 깊이 배우기보단 취업입니다. 때문에 기업들 또는 제가 원하는 기업이 원하는 인재상이 되고 싶습니다.
3. 4학년 때는 아무래도 졸업이 우선입니다.
   그래서 1순위가 졸업이고 2순위가 정보처리기사 공동 3순위가 취업과 포폴입니다. 아무래도 졸업장을 따야 취업을 할 수 있으니 말입니다.
