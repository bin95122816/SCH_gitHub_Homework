# SCH_gitHub_Homework
자기주도학습 githib과제

아직 진로가 정해지지 않았습니다.
그래서 억지로 쓰기보다 2학년 1학기 방학 계획을 쓰고자 합니다. 

git/gitHub랑 Linux 공부할 생각입니다. 
둘다 공통적으로 코딩을 하는 사람으로서 알아야한다는 이야기를 들었습니다.
실제로 협업을 위해서 git/gitHub를 많이 사용하는데, 어떤 일로 인해 깃허브를 하게 되었는데 쉽지 않더라고요.
아무래도 지금은 다른사람과 협업하는 일이 없다보니 당장은 문제가 없겠지만, 추후 힘들어질 수 있으니 공부할 생각입니다.

Linux도 알면 좋다고 들어서 일단 교재를 살 예정입니다. 

하지만 이론만 배우면 금방 잊기도 하고 직접 경험하는 게 좋다고 생각되어 작은 규모의 프로젝트로 실습도 병행해볼까 합니다.
영단어 책 사놓은게 있어서 그걸 이용하여 영단어장을 만들 예정입니다. 
비록 아직 미숙한 실력이기에 AI를 이용하되 왜 이런 코드인가, 이 방법 말고도 이런 방법이 있지 않은가의 방식으로 결과보다 '만드는 과정'에 중점을 둘 것입니다.

그래도 과제가 '진로계횟 작성'이니까 간략하게 써보겠습니다.
